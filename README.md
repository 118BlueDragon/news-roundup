# 资讯速览 · 行业资讯每日更新

状态：🟢 持续运营（自动更新）｜ 形态：单页静态站点 ｜ 更新：约每 15 分钟

## 这是什么

把分散的公开行业资讯按主题聚合，生成一个浏览器直接可读的静态页面，
用于内部选题与内容分发参考。

## 主要能力

- 定时抓取公开来源，自动去重、归类
- 生成单页摘要，免登录、手机可直接浏览
- 页面轻量：仓库根目录只有一个 `index.html`

## 浏览方式

`index.html` 即当前页面，任意静态托管或本地打开都能读。

## 更新与版本

由本地定时任务自动提交，提交信息形如 `update MM-DD HH:MM`；无正式版本号。

## 边界与声明

- 仅聚合公开信息并标注来源，不做全文转载与二次售卖。
- 页面不含客户信息、账户凭据与内部部署细节。
